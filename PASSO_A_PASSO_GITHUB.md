# Como publicar no GitHub — explicado bem devagar

Imagine que o GitHub é uma caixa e o site são brinquedos que vamos colocar dentro dela.

## 1. Abra a pasta
1. Baixe o arquivo ZIP.
2. Clique com o botão direito.
3. Clique em **Extrair tudo**.
4. Abra a pasta extraída.

Você verá `index.html`, `styles.css`, `app.js` e a pasta `data`. Não apague nada.

## 2. Crie uma caixa nova no GitHub
1. Entre em `github.com` e faça login.
2. Clique no sinal **+** no alto da tela.
3. Clique em **New repository**.
4. Em **Repository name**, escreva `meu-radar-leiloes`.
5. Marque **Public**.
6. Clique em **Create repository**.

## 3. Coloque os arquivos na caixa
1. Clique em **Add file**.
2. Clique em **Upload files**.
3. Arraste TODOS os arquivos e pastas da pasta extraída para a tela do GitHub.
4. Espere terminar.
5. Em **Commit changes**, escreva `Primeira versão do site`.
6. Clique no botão verde **Commit changes**.

## 4. Ligue o site
1. Clique em **Settings** dentro do repositório.
2. No menu esquerdo, clique em **Pages**.
3. Em **Source**, escolha **Deploy from a branch**.
4. Em **Branch**, escolha `main`.
5. Ao lado, escolha `/(root)`.
6. Clique em **Save**.
7. Espere de 1 a 5 minutos.

O endereço ficará parecido com:

`https://SEU-USUARIO.github.io/meu-radar-leiloes/`

## 5. Atualizar depois
1. Entre no repositório.
2. Clique em **Add file > Upload files**.
3. Arraste os arquivos atualizados.
4. Confirme a substituição.
5. Clique em **Commit changes**.
6. Espere alguns minutos.

## Aviso de privacidade
Mesmo sendo para seu uso, um site público pode ser encontrado por outras pessoas. Não coloque senhas, CPF, cartão, dados bancários ou credenciais de sites de leilão dentro dos arquivos.
