# Meu Radar de Leilões

Versão estática pronta para GitHub Pages.

## Recursos
- Busca por item, cidade, estado, categoria e referência.
- Filtros por estado, cidade, categoria e site.
- Ordenação por data e lance.
- Detalhes em janela e botão para anúncio oficial.
- Layout responsivo e tema claro/escuro.

## Limitação importante
O GitHub Pages publica HTML, CSS e JavaScript, mas não executa robôs de busca em vários sites. Nesta primeira versão, os dados ficam em `data/leiloes.json`. Depois poderá ser conectada uma API externa.
